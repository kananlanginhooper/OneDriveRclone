OneDriveRclone

A personal backup tool. It uses rclone to copy files from a home server to a folder in the owner's own OneDrive, as a second offsite backup copy — the irreplaceable subset (taxes, legal and identity papers, personal documents) alongside the primary offsite copy on Google Drive.

What it does

  • Runs on the owner's own hardware, for the owner's own files only.
  • Copies files one-way, from the home server to OneDrive. It never deletes or modifies anything already in OneDrive that it didn't put there.
  • Single-user: only the account owner signs in and uses it, on their own personal Microsoft account.
