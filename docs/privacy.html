Privacy policy — OneDriveRclone

Last updated 2026-09-27.

OneDriveRclone is a personal, single-user tool. It is not a public service, and it is not offered to anyone besides its owner. This page exists to meet Microsoft's app registration requirements for the OneDrive/Microsoft Graph "Files" permissions it requests.

What data it accesses

The app requests OneDrive file read/write access (Microsoft Graph Files.ReadWrite) for the signed-in personal Microsoft account only. It writes to a single folder it creates for its own uploads.

What it does with that access

It uploads a one-way copy of a specific set of files (the owner's irreplaceable documents — tax, legal, identity and personal records) from the owner's own home server into that folder in the owner's own OneDrive, as a backup. It reads back a checksum to confirm each upload matches the original. It does not read, download, or alter any other content in the OneDrive account.

What is not done

  • No data is sold, shared, or shown to any third party.
  • No data is used for advertising.
  • No human other than the account owner reviews the uploaded content.
  • Nothing is collected outside of the files the owner chooses to back up.

Data retention

Uploaded files stay in the owner's own OneDrive under the owner's control, and can be deleted by the owner at any time through OneDrive itself. The app keeps no separate copy or log of file contents; it keeps only a local record (on the owner's own server) of which files it has already uploaded, to avoid re-uploading them.
